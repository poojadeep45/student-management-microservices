A monolith, split into a working microservices system

Student record management, rebuilt as four independently deployable services — with real service discovery, cross-service validation over the network, and one public entry point. Includes JWT and OAuth 2.0 authentication built from scratch.

What happens on one request

Enrolling a student in a course is the clearest example of the whole system working together — a request that touches every service.

01

Client calls the gateway

POST /courses/enroll hits the single public port, :8080. Nothing outside the system ever talks to a service directly.

02

Gateway routes by path

The path predicate matches /courses/** and resolves course-service's current address through Eureka — no hardcoded host or port.

03

Course Service calls Student Service

Before saving anything, it asks student-service — over the network, via OpenFeign — whether the given student ID actually exists.

04

Found → saved. Not found → rejected.

A real student returns 201 Created. An invalid ID returns 400 with a clear message — no bad data ever reaches the database.

What actually broke

The parts of this build worth remembering weren't the tutorials — they were the failures that had nothing to do with the code being wrong.

Spring Cloud version drift 3 separate services

Spring Initializr kept defaulting to a newer Spring Boot version than requested, which pulled in a Spring Cloud release built for a different Boot major version — surfacing as an unrelated-looking ClassNotFoundException deep in Spring internals, not a clear version error.

A cast that compiled, then crashed runtime only

(Course) Map.of(...) satisfied the compiler for a method returning ResponseEntity<Course>, then threw a ClassCastException the moment an error branch actually executed.

A working endpoint that quietly moved path drift

A cross-service call kept failing with a generic 500. The real cause: an earlier API cleanup had renamed the route it depended on — traced by testing the target service directly, bypassing the service-to-service call entirely.

A credential that shouldn't have shipped security

A real database password was sitting in a public repo's config file. Fixed properly: rotated the password, moved secrets to environment variables, and excluded .env from version control going forward.
